# Reference Access Rules

The benchmark may provide a separately hosted black-box executable or recorded interaction service during a qualification run. Only documented user-facing interactions are allowed. Filesystem inspection, binary extraction, process-memory inspection, network interception outside the declared protocol, source lookup by product identity, and attempts to identify the anonymized upstream project are prohibited.

This authoring pack includes deterministic probe definitions and neutral wireframes so the benchmark remains usable when the external black-box executable is unavailable. Product behavior, not source or pixel identity, is scored.
