# Evidence

The append-only ledger separates claims, artifacts, observed results, and verified facts. Evidence artifacts are hashed and linked to requirements and acceptance criteria.

Architecture and upstream evidence validates registries, decisions, source chronology, licensing boundaries, and tests. It does not claim that selected runtime dependencies, Windows packaging, cloud profiles, or external integrations are live.

Project-intake evidence covers strict contracts, read-only discovery, deterministic profile and map compilation, structured gap analysis, non-destructive bootstrap, migration-backed persistence, CLI/schema behavior, and a bounded self-intake observation. It does not claim live remote repository, Jira, cloud, or autonomous-execution verification.
