# ProjectPipeline Support

Choose the channel that best matches your request:

| Need | Channel |
| --- | --- |
| Setup or usage question | [GitHub Discussions](https://github.com/KevinSGarrett/ProjectPipeline/discussions) |
| Design idea or general feedback | [GitHub Discussions](https://github.com/KevinSGarrett/ProjectPipeline/discussions) |
| Reproducible software defect | [Bug report](https://github.com/KevinSGarrett/ProjectPipeline/issues/new?template=bug_report.yml) |
| Concrete product improvement | [Feature request](https://github.com/KevinSGarrett/ProjectPipeline/issues/new?template=feature_request.yml) |
| Suspected vulnerability | [Private vulnerability report](https://github.com/KevinSGarrett/ProjectPipeline/security/advisories/new) |
| Community conduct concern | [Code of Conduct](CODE_OF_CONDUCT.md#reporting-and-enforcement) |

Before asking for help, search existing discussions and issues, include the ProjectPipeline version or commit, and provide a minimal reproduction where possible. Sanitize logs and screenshots; never post credentials, private repositories, customer data, or local project-control records.

ProjectPipeline does not currently offer a guaranteed support response time. Community questions are answered as maintainer availability permits.
