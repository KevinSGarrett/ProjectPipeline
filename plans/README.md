
# Technical Planning Corpus

The planning corpus is divided by system responsibility. Every plan has a stable ID, stable section IDs, source basis, explicit status, and machine-readable catalog entry. Cross-references use identifiers rather than relative phrases.

`PLAN_CATALOG.json` is the navigation authority. `_line_numbered/` contains generated line-addressable copies for work-item references. `_traceability/` contains source, requirement, work, implementation, test, and evidence mappings.

Plans describe accepted or proposed design. They are not evidence that the corresponding runtime is implemented.

`PLAN-PDEF-002` is the current authority for safe project discovery, deterministic intake compilation, profile detection, repository mapping, gap analysis, and controlled bootstrap behavior.
