# Architecture Diagrams

These Mermaid files are architecture-as-code views. Machine-readable component, state, boundary, flow, profile, technology, and decision registries remain authoritative if a diagram differs.

- `system_context.mmd` — external context and primary dependencies.
- `component_layers.mmd` — logical layers and dependency direction.
- `authority_and_trust.mmd` — deterministic and probabilistic authority boundary.
- `durable_command_flow.mmd` — command ledger, outbox, workflow, and reconciliation flow.
- `deployment_profiles.mmd` — local-first and optional cloud topology.
- `traceability_flow.mmd` — bidirectional source-to-evidence chain.
