
# Continuation Package Contract

A continuation package is separate from the permanent Project Pipeline repository. It carries the governing execution contract, current delivery state, blockers, decisions, coverage, work status, implementation status, test status, recent changes, expected project archive, hashes, and the authoritative source inputs needed by a new execution environment.

It may contain session-specific execution language and raw source material that the permanent repository intentionally excludes. It must never depend upon undocumented conversation history. The package is source-bearing and therefore uses archive-integrity checks without applying permanent-repository terminology policy to the enclosed raw inputs.
